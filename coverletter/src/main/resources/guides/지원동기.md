# 지원동기 작성 가이드

목적: "왜 이 회사, 왜 이 직무, 왜 지금"을 공고 사실과 내 사실로만 연결하는 항목.

쓰는 법
- 공고의 구체 요소(제품, 서비스, 채용 직무 요구)에서 1개를 찾아 내 경력과 연결한다
- [관심의 계기] [내가 준비하고 증명한 것] [이 회사에서 하고 싶은 일] 3단 구조
- 회사명, 서비스명, 직무명이 본문에 반드시 등장한다
- 다른 회사에 바꿔 끼우면 어긋나는 문장이 1개 이상 있어야 한다

피할 것
- 어디에나 붙는 으리 문장 ("혁신적인 기업", "탄탄한 기술 스택")
- 회사 언급 없는 범용 칭찬
- 근거 없는 상상 문장 (근거가 있으면 한 문장으로만)
