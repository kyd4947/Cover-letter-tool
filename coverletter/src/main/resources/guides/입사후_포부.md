# 입사 후 포부 작성 가이드

목적: 입사 후 무엇을 만들고 어디로 확장되는지를 직무로 풀어내는 항목. 다짐서가 아니다.

쓰는 법
- [입사 초기: 적응과 파악] [담당 업무에서 만들 것] [1~3년 확장 방향] 3단 시간 축
- 업무의 종류를 쓴다: 무엇을, 어떤 방법으로, 어떤 형태의 결과로
- 공고의 요구역량을 1개 이상 받아서 연결한다

피할 것
- "최선을 다하겠습니다", "배우겠습니다"로 항목을 닫는 스타일
- 직무와 무관한 개인 장기 로드맵
- 다른 항목에서 이미 쓴 경력의 반복

기대 그림: "입사 3개월 뒤 이 사람이 하는 일"이 떠오르는 문장이 1개 이상 있다.
