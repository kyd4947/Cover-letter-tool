# 성장과정 작성 가이드

목적: 사건 1~2개로 "이 사람의 기준과 습관이 어떻게 생겼는지" 근거를 만드는 항목. 전생 연대기가 아니다.

쓰는 법
- 지원 직무, 전공, 지원 회사 문화와 이어지는 사건만 고른다
- [상황] [문제·의문] [내가 한 것] [바뀐 기준·습관] 4단 구조로 쓴다
- 종결 문장은 행동·방향으로 마무리한다
- 전공 역량·프로젝트 상세는 다른 항목이 맡는다 (중복 최소화)

피할 것
- 가족사·취미·수상 목록 나열
- 열심, 성실 같은 형용사 반복
- "그 경험 덕분에 노력하는 사람이 되었습니다" 류 교훈 종결
